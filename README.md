# 네이버 블로그 글쓰기 도우미 (사내용)

사진을 올리면 AI(Claude)가 사진을 보고 **블로그 주제를 추천**하고, 고른 주제로 **네이버 블로그 글을 작성**해 주는 사내 웹 프로그램입니다.

## 사용 흐름

1. **사진 올리기** — 사진(최대 20장)을 올리고 블로그명·업종·말투·키워드·메모를 적습니다.
   - 사진 순서가 곧 글 속 `[사진 N]` 번호입니다. 썸네일을 끌어서 순서를 바꿀 수 있습니다.
   - 가격·영업시간·이벤트처럼 사진에 없는 사실은 **메모**에 적어 주세요. AI는 메모에 없는 사실을 지어내지 않고 `[가격 입력]` 같은 자리표시로 남깁니다.
2. **주제 선택** — AI가 사진을 분석해 서로 다른 관점의 주제 4개(제목, 구성 방향, 대상 독자, 메인/서브 키워드)를 제안합니다. 하나를 고르고 분량을 정합니다.
3. **글 확인·복사** — 제목, 소제목별 본문, 사진 배치, 해시태그, 올리기 전 확인할 항목이 나옵니다.
   - 본문은 화면에서 바로 고칠 수 있습니다.
   - **사진 순서대로 받기 (ZIP)** — 글에 배치된 순서대로 `01_사진3.jpg`처럼 번호를 붙인 원본 사진 묶음을 내려받습니다.
4. **네이버 에디터로 보내기** — 네이버 글쓰기 화면이 새 탭으로 열립니다.
   - 크롬 확장 프로그램이 설치돼 있으면: 에디터 오른쪽 아래 패널의 **제목·본문 채워 넣기**를 누릅니다.
   - 확장 프로그램이 없으면: 본문이 클립보드에 복사돼 있으니 에디터 본문에 `Ctrl+V` 합니다.
   - 사진은 `[사진 N]` 자리에 넣고, 태그는 발행 창에 넣은 뒤 **발행은 담당자가 직접** 누릅니다.

### 글 보관함과 발행 일정

글을 미리 여러 개 만들어 두고 정해 둔 시각에 올리는 방식입니다.

1. 3단계에서 **발행 예정 시각**을 정하고 **보관함에 저장**합니다. 시각을 비우면 임시저장입니다.
   사진 원본도 서버에 함께 저장됩니다.
2. 상단 **글 보관함** 탭에서 발행 예정 / 임시저장 / 발행 완료 글을 보고, 열어서 고치거나 지울 수 있습니다.
3. 예정 시각이 되면 크롬 확장이 **알림**을 띄우고 툴바 아이콘에 올릴 글 수를 표시합니다.
   알림을 누르면 네이버 에디터가 열리고, 패널에서 **채워 넣기**와 **사진 받기(ZIP)**를 바로 쓸 수 있습니다.
4. 발행 후 패널의 **발행했어요**를 누르면 보관함에 "발행 완료"로 표시됩니다.

> 미리 몰아서 올려 두고 싶다면: 에디터에 채운 뒤 네이버 발행 창의 **예약**에 같은 시각을 넣으면 네이버가 그 시각에 직접 발행합니다.
> 알림은 크롬이 켜져 있을 때 1분마다 확인합니다.

> 네이버는 블로그 글쓰기 API를 제공하지 않습니다. 로그인·발행까지 자동으로 하는 방식은 계정 제재 위험이 있어,
> 발행 직전까지만 돕는 반자동 방식으로 만들었습니다.

## 설치 (처음 한 번, 약 5분)

### 1. 서버 PC에서 실행
도우미를 켜 둘 PC 한 대(윈도우 또는 맥)에서 이 폴더를 받은 뒤:

| 윈도우 | 맥 |
|---|---|
| **`시작하기.bat`** 더블클릭 | **`시작하기.command`** 더블클릭 (처음엔 *우클릭 → 열기*) |

처음 실행하면 파이썬과 필요한 프로그램을 자동으로 설치하고(1~3분), 브라우저에서 도우미가 열립니다.
다음부터는 같은 파일을 누르면 바로 켜집니다. 검은 창을 닫으면 도우미가 꺼집니다.

> 파이썬 자동 설치가 안 되는 PC(winget/Homebrew 없음)는 python.org 다운로드 페이지가 열립니다.
> 설치 후 같은 파일을 다시 실행하세요. 윈도우는 설치 첫 화면에서 **Add python.exe to PATH**를 체크하세요.

### 2. 설정 화면에서 AI 연결
처음 열리면 **설정** 화면이 나옵니다. 쓸 AI를 고르고 API 키를 붙여넣은 뒤 **저장하고 확인**을 누르면 끝입니다.

| | 구글 제미나이 | Claude |
|---|---|---|
| 비용 | 무료 사용량 있음 (분당·하루 횟수 제한) | 쓴 만큼 충전 (글 1편 수백 원 수준) |
| 키 받는 곳 | [Google AI Studio](https://aistudio.google.com/apikey) → API 키 만들기 | [Claude 콘솔](https://console.anthropic.com/settings/keys) → Create Key, 결제에서 크레딧 충전 |

키가 맞는지 바로 확인해 주고(제미나이는 계정에서 쓸 수 있는 Flash 모델을 자동으로 고릅니다),
블로그명·업종·말투 기본값도 여기서 정합니다. 두 키를 다 넣어 두면 설정 화면에서 언제든 바꿔 쓸 수 있습니다.

> 제미나이 무료 사용 시 올린 내용이 구글 서비스 개선에 쓰일 수 있습니다. 민감한 정보는 메모에 넣지 마세요.

> 설정(특히 API 키)은 **서버 PC에서만** 바꿀 수 있습니다. 다른 PC·휴대폰에서는 보기만 됩니다.

### 3. 다른 PC·휴대폰에서 접속
설정 화면의 **다른 PC·휴대폰에서 쓰기**에 나오는 주소(예: `http://192.168.0.10:8000`)로 들어오면 됩니다.
휴대폰은 QR 코드를 찍고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다. 같은 와이파이/사내망에서만 접속됩니다.

### 4. 크롬 확장 프로그램 (PC마다, 선택)
에디터 자동 채우기와 발행 알림을 쓰려면 각 PC에서:
1. 도우미의 **설정 → 크롬 확장 프로그램 → 받기**로 설치 파일을 받아 압축을 풉니다. (서버 주소가 이미 들어 있습니다)
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 `블로그도우미_확장프로그램` 폴더 선택

확장은 `blog.naver.com`과 도우미 서버 주소에서만 동작하며 네이버 로그인 정보에는 접근하지 않습니다.
스마트에디터 구조가 바뀌어 자동 채우기가 안 되면 패널의 복사 버튼을 쓰고,
`extension/editor.js` 위쪽의 `TITLE_SELECTORS` / `BODY_SELECTORS`를 고치면 됩니다.

### 5. PC 켤 때 자동 실행 (선택)
**`자동실행_설정.bat`**(윈도우) / **`자동실행_설정.command`**(맥)를 실행하면 PC를 켤 때 도우미가 자동으로 켜집니다.
다시 실행하면 해제됩니다. 맥은 폴더를 데스크탑·문서·다운로드가 아닌 홈 폴더에 두는 것을 권장합니다.

### 개발자용 수동 실행

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

### 고급 설정 (`.env`, 선택)

보통은 설정 화면으로 충분합니다. `.env`에 값을 넣으면 설정 화면 값보다 우선합니다.

| 항목 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키 (설정 화면 대신 지정할 때) |
| `BLOG_PROVIDER` | 쓸 AI (`claude` / `gemini`) |
| `GEMINI_API_KEY`, `GEMINI_MODEL` | 제미나이 키와 모델 (모델은 비우면 자동 선택) |
| `BLOG_MODEL` | Claude 모델. 기본 `claude-opus-5-5` |
| `BLOG_NAME`, `BLOG_INDUSTRY`, `BLOG_TONE` | 화면 입력칸의 기본값 |
| `BLOG_WRITE_URL` | "네이버 에디터로 보내기"가 여는 주소. 기본은 로그인한 계정의 글쓰기 화면 |
| `HOST`, `PORT` | 서버 주소/포트. 기본 `0.0.0.0:8000` |
| `BLOG_DATA_DIR` | 보관함·설정 저장 폴더. 기본 `data/` — 백업은 이 폴더를 복사하면 됩니다 |
| `BLOG_ADMIN_PASSWORD` | 클라우드 등 프록시 뒤에서 운영할 때, 설정 화면을 이 비밀번호로 열기 |

## 구조

```
app/
  main.py      FastAPI 서버 (API + 화면 제공)
  writer.py    주제 추천 / 글 작성 프롬프트와 응답 형식(JSON 스키마), Claude 호출
  gemini_writer.py  같은 프롬프트로 제미나이 호출
  images.py    사진 회전 보정·축소·JPEG 변환
  store.py     글 보관함 (SQLite + 사진 파일)
  settings.py  설정 화면 값 저장 (data/settings.json)
  setup.py     API 키 확인, 접속 주소·QR, 확장 설치 파일 만들기
  static/      화면 (index.html, app.js, zip.js, style.css)
extension/     크롬 확장 프로그램 — 에디터 채워 넣기, 발행 시각 알림
tests/         테스트 (Claude 호출은 가짜 클라이언트로 대체)
시작하기.bat / 시작하기.command        원클릭 설치·실행 (윈도우 / 맥)
자동실행_설정.bat / 자동실행_설정.command  PC 켤 때 자동 실행 켜기/끄기
```

- 글의 톤이나 규칙을 바꾸려면 `app/writer.py`의 `SYSTEM_PROMPT`를 수정하세요.
- 주제 추천~글 작성 사이의 사진은 서버 메모리에 2시간만 보관됩니다. 보관함에 저장한 글과 사진만 `data/`에 남습니다.
- 메모리 보관 방식이라 서버는 **프로세스 1개**로 실행해야 합니다 (`--workers` 여러 개 X).

## 비용 참고

사진은 긴 변 1568px로 줄여서 보냅니다. 사진 10장 기준으로 주제 추천 1회 + 글 작성 1회에 대략 수백 원 수준입니다 (모델·분량에 따라 다름). 비용을 줄이려면 `.env`에서 `BLOG_MODEL=claude-sonnet-5-5`로 바꿀 수 있습니다.
