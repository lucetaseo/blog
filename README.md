# 네이버 블로그 글쓰기 도우미 (사내용)

사진을 올리면 AI(Claude)가 사진을 보고 **블로그 주제를 추천**하고, 고른 주제로 **네이버 블로그 글을 작성**해 주는 사내 웹 프로그램입니다.

## 사용 흐름

1. **사진 올리기** — 사진(최대 20장)을 올리고 블로그명·업종·말투·키워드·메모를 적습니다.
   - 사진 순서가 곧 글 속 `[사진 N]` 번호입니다. 썸네일을 끌어서 순서를 바꿀 수 있습니다.
   - 가격·영업시간·이벤트처럼 사진에 없는 사실은 **메모**에 적어 주세요. AI는 메모에 없는 사실을 지어내지 않고 `[가격 입력]` 같은 자리표시로 남깁니다.
2. **주제 선택** — AI가 사진을 분석해 서로 다른 관점의 주제 4개(제목, 구성 방향, 대상 독자, 메인/서브 키워드)를 제안합니다. 하나를 고르고 분량을 정합니다.
3. **글 확인·복사** — 제목, 소제목별 본문, 사진 배치, 해시태그, 올리기 전 확인할 항목이 나옵니다.
   - 본문은 화면에서 바로 고칠 수 있습니다.
   - **사진 순서대로 받기 (ZIP)** — 글에 배치된 순서대로 `01_사진3.jpg`처럼 번호를 붙인 원본 사진 묶음을 내려받습니다.
4. **네이버 에디터로 보내기** — 네이버 글쓰기 화면이 새 탭으로 열립니다.
   - 크롬 확장 프로그램이 설치돼 있으면: 에디터 오른쪽 아래 패널의 **제목·본문 채워 넣기**를 누릅니다.
   - 확장 프로그램이 없으면: 본문이 클립보드에 복사돼 있으니 에디터 본문에 `Ctrl+V` 합니다.
   - 사진은 `[사진 N]` 자리에 넣고, 태그는 발행 창에 넣은 뒤 **발행은 담당자가 직접** 누릅니다.

### 글 보관함과 발행 일정

글을 미리 여러 개 만들어 두고 정해 둔 시각에 올리는 방식입니다.

1. 3단계에서 **발행 예정 시각**을 정하고 **보관함에 저장**합니다. 시각을 비우면 임시저장입니다.
   사진 원본도 서버에 함께 저장됩니다.
2. 상단 **글 보관함** 탭에서 발행 예정 / 임시저장 / 발행 완료 글을 보고, 열어서 고치거나 지울 수 있습니다.
3. 예정 시각이 되면 크롬 확장이 **알림**을 띄우고 툴바 아이콘에 올릴 글 수를 표시합니다.
   알림을 누르면 네이버 에디터가 열리고, 패널에서 **채워 넣기**와 **사진 받기(ZIP)**를 바로 쓸 수 있습니다.
4. 발행 후 패널의 **발행했어요**를 누르면 보관함에 "발행 완료"로 표시됩니다.

> 미리 몰아서 올려 두고 싶다면: 에디터에 채운 뒤 네이버 발행 창의 **예약**에 같은 시각을 넣으면 네이버가 그 시각에 직접 발행합니다.
> 알림은 크롬이 켜져 있을 때 1분마다 확인합니다.

> 네이버는 블로그 글쓰기 API를 제공하지 않습니다. 로그인·발행까지 자동으로 하는 방식은 계정 제재 위험이 있어,
> 발행 직전까지만 돕는 반자동 방식으로 만들었습니다.

## 크롬 확장 프로그램 설치 (담당자 PC마다 1회)

1. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 저장소의 `extension` 폴더 선택
3. 도우미 서버가 내 PC의 기본 주소(`http://localhost:8000`)가 아니라면: 툴바의 확장 아이콘을 눌러 설정 화면에서 서버 주소(예: `http://192.168.0.10:8000`)를 저장하고 권한을 허용
4. 도우미 화면을 새로고침하면 3단계에 "✅ 확장 프로그램 연결됨"이 표시됩니다.

확장은 `blog.naver.com`과 등록한 도우미 서버 주소에서만 동작합니다. 네이버 로그인 정보에는 접근하지 않습니다.

**스마트에디터 화면 구조가 바뀌어 자동 채우기가 안 되면** 패널의 복사 버튼으로 붙여넣으면 되고,
`extension/editor.js` 위쪽의 `TITLE_SELECTORS` / `BODY_SELECTORS`만 고치면 다시 동작합니다.

## 설치 및 실행

Python 3.10 이상이 필요합니다.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # Windows: copy .env.example .env
# .env 파일을 열어 ANTHROPIC_API_KEY 를 입력

python -m app.main
```

브라우저에서 `http://localhost:8000` (다른 PC에서는 `http://<서버IP>:8000`)으로 접속합니다.

### 설정 (`.env`)

| 항목 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키 (필수) |
| `BLOG_MODEL` | 사용할 모델. 기본 `claude-opus-5-5` |
| `BLOG_NAME`, `BLOG_INDUSTRY`, `BLOG_TONE` | 화면 입력칸의 기본값 |
| `BLOG_WRITE_URL` | "네이버 에디터로 보내기"가 여는 주소. 기본은 로그인한 계정의 글쓰기 화면 |
| `HOST`, `PORT` | 서버 주소/포트. 기본 `0.0.0.0:8000` |
| `BLOG_DATA_DIR` | 보관함(DB, 사진) 저장 폴더. 기본 `data/` — 백업은 이 폴더를 복사하면 됩니다 |

## 구조

```
app/
  main.py      FastAPI 서버 (API + 화면 제공)
  writer.py    Claude 호출 — 주제 추천 / 글 작성 프롬프트와 응답 형식(JSON 스키마)
  images.py    사진 회전 보정·축소·JPEG 변환
  store.py     글 보관함 (SQLite + 사진 파일)
  static/      화면 (index.html, app.js, zip.js, style.css)
extension/     크롬 확장 프로그램 — 에디터 채워 넣기, 발행 시각 알림
tests/         테스트 (Claude 호출은 가짜 클라이언트로 대체)
```

- 글의 톤이나 규칙을 바꾸려면 `app/writer.py`의 `SYSTEM_PROMPT`를 수정하세요.
- 주제 추천~글 작성 사이의 사진은 서버 메모리에 2시간만 보관됩니다. 보관함에 저장한 글과 사진만 `data/`에 남습니다.
- 메모리 보관 방식이라 서버는 **프로세스 1개**로 실행해야 합니다 (`--workers` 여러 개 X).

## 비용 참고

사진은 긴 변 1568px로 줄여서 보냅니다. 사진 10장 기준으로 주제 추천 1회 + 글 작성 1회에 대략 수백 원 수준입니다 (모델·분량에 따라 다름). 비용을 줄이려면 `.env`에서 `BLOG_MODEL=claude-sonnet-5-5`로 바꿀 수 있습니다.
